NAJPROSTSZE WGRANIE PRZEZ GITHUB
1. Rozpakuj tę paczkę na komputerze.
2. Otwórz GŁÓWNY KATALOG repozytorium poradnik.eazbiuro.pl.
3. Wybierz Add file > Upload files.
4. Przeciągnij całą ZAWARTOŚĆ rozpakowanej paczki, łącznie z folderami:
   .github, assets i tools.
   Na komputerze Mac folder .github może być ukryty — naciśnij Command + Shift + kropka,
   aby go wyświetlić przed zaznaczeniem plików.
5. Zatwierdź Commit changes.
6. GitHub Actions automatycznie:
   - utworzy tag zapasowy „backup-przed-przebudowa-...”,
   - przebuduje wszystkie pliki HTML,
   - skontroluje kompletność,
   - zapisze zmiany w repozytorium.
7. W zakładce Actions sprawdź, czy zadanie „Przebuduj wygląd poradnika”
   zakończyło się zielonym znakiem.

WAŻNE
Jeżeli GitHub zgłosi brak prawa do zapisu:
Settings > Actions > General > Workflow permissions > Read and write permissions > Save,
a następnie Actions > Przebuduj wygląd poradnika > Run workflow.

WGRANIE LOKALNE
